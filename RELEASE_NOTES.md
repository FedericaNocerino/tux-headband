# Prototype release notes

## Initial GitHub package

- Added editable parametric OpenSCAD source.
- Added matching nominal male/female quarter-turn bayonet geometry.
- Added headband/socket, male adapter, fit coupon, and assembly-preview STL exports.
- Added print notes, contribution guidance, and MIT license.

Physical fit, comfort, retention, and strength remain unvalidated. The included `assembly_preview.stl` is for visualization and should not be printed as one part.
